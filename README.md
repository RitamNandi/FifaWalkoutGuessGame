# FifaWalkoutGuessGame
Guess the player based on the nation, position, and country (similar to card walkouts in EAFC/Fifa)
* Deployed at https://ritamnandi.github.io/FifaWalkoutGuessGame/
* Backend: FastAPI. cd api, pip install -r requirements.txt, uvicorn index:app --reload.
* Frontend: React. cd frontend, npm run dev
